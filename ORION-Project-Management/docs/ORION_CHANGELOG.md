2. ما الذي يتم تسجيله؟
==================================================

يتم تسجيل التغييرات المهمة مثل:

- المكونات الجديدة.
- التعديلات المعمارية.
- الإصلاحات المهمة.
- تغيرات تدفق البيانات أو العقود.
- الاختبارات المهمة.
- تغييرات الإعدادات والتخزين وProvider وEngines وAPI وGUI وScheduler.
- تغييرات أدوات المشروع أو بنية المستودع أو المزامنة.
- تغييرات وثائق المشروع.
- الإصدارات الرسمية.

لا يحتاج كل تصحيح شكلي أو إملائي إلى سجل مستقل.
