3. قاعدة المصدر الواحد
==================================================

كل معلومة لها مالك رئيسي واحد فقط.

لا يجوز نسخ نفس القاعدة أو الحالة أو الخطة كاملة إلى وثيقة أخرى.

يمكن للوثيقة غير المالكة أن تحتوي على:

- إشارة مختصرة.
- رابط إلى الوثيقة المالكة.
- سبب اعتماد المعلومة إذا كان ذلك ضروريًا لفهم سياقها.

لكن لا تنشئ نسخة مستقلة من المعلومة.

5. متى نقرأ الوثائق
==================================================

رسالة ORION عادية

→ EXECUTION RULES + CONTROL INDEX + PROJECT STATE + ROADMAP
→ ثم الوثائق المطلوبة للخطوة.

مراجعة تطوير
→ EXECUTION RULES + CONTROL INDEX
→ PROJECT STATE عند الحاجة
→ ARCHITECTURE + FINDINGS
→ الملفات المتغيرة + الاختبارات
→ FUTURE ROADMAP عند وجود أثر مستقبلي.

تعديل معماري
→ EXECUTION RULES + CONTROL INDEX + PROJECT STATE
→ ARCHITECTURE + FINDINGS + DECISIONS + ROADMAP
→ FUTURE ROADMAP عند وجود أثر طويل الأجل.

تعديل Workflow أو المزامنة
→ EXECUTION RULES + CONTROL INDEX + WORK PROTOCOL
→ الأدوات التشغيلية المرتبطة.

تعديل الوثائق
→ EXECUTION RULES + CONTROL INDEX
→ الوثائق المتأثرة فقط، مع البحث عن التكرار أو التعارض عند الحاجة.

مشكلة مؤكدة
→ EXECUTION RULES + CONTROL INDEX + KNOWN PROBLEMS
→ الملفات المرتبطة.

تعارض أو مراجعة شاملة
→ مراجعة موسعة لجميع الوثائق المتأثرة.

6. قاعدة تنظيف الوثائق
==================================================

عند اكتشاف تكرار أو تعارض:

1. تحديد الوثيقة المالكة.
2. اعتماد أحدث حالة/قرار مثبت.
3. إزالة المحتوى المكرر من الوثائق غير المالكة.
4. استبداله بمرجع مختصر عند الحاجة.
5. عدم حذف التاريخ من CHANGELOG أو القرارات أو Findings المغلقة.
