==================================================
13. المزامنة
==================================================

لا تتم المزامنة بعد كل تعديل صغير.

عند وجود مجموعة تعديلات مرتبطة:

1. يتم إعداد جميع التعديلات.
2. يتم تطبيقها محليًا.
3. يتم حفظ الملفات.
4. يتم إجراء الاختبارات أو التحقق المطلوب.
5. تتم مراجعة المجموعة كاملة.
6. يتم اعتماد المجموعة.
7. يتم تشغيل أداة المزامنة مرة واحدة.
8. يتم Commit.
9. يتم Push إلى GitHub.
10. يتم التحقق من النتيجة.

الهدف هو تنفيذ المزامنة مرة واحدة لكل مجموعة مكتملة.

2. يتم تحديد التعديل.
3. يتم إعداد النسخة الكاملة الجديدة.

7. تتم المزامنة Local → GitHub.

وجود إمكانية الوصول إلى GitHub لا يعني أن GitHub هو بيئة التعديل الأساسية.
