==================================================
4. حالات القرار
==================================================

PROPOSED
مقترح ولم يعتمد بعد.

ACCEPTED
تم اعتماد القرار.

REJECTED
تم رفض القرار.

SUPERSEDED
تم استبداله بقرار أحدث.

DEPRECATED
لم يعد القرار مناسبًا للتطبيق الحالي.

2026-08-08

ACCEPTED

المجال:

Architecture

وجود جميع المسؤوليات داخل طبقة أو مجموعة ملفات غير منظمة
سيؤدي إلى صعوبة الصيانة والتوسع والاختبار.

### القرار

اعتماد بنية متعددة الطبقات تفصل بين:

- API
- Application
- Bootstrap
- Configuration
- Core
- Engines
- GUI
- Models
- Providers
- Reports
- Repositories
- Scheduler
- Services
- Storage
- Tests

### السبب

فصل المسؤوليات وإدارة الاعتماديات وتطوير المكونات
بصورة مستقلة نسبيًا.

### التأثير

يجب الحفاظ على حدود الطبقات ما لم يتم اتخاذ قرار
معماري جديد.

### الحالة

ACCEPTED

ADR-007 — اعتماد GPT كصاحب القرار الفني النهائي
--------------------------------------------------

التاريخ:

2026-08-08

الحالة:

ACCEPTED

المجال:

Project Governance

### السياق

يحتاج ORION إلى جهة واحدة مسؤولة عن التحليل الفني
والقرار المعماري واستمرارية المنهج.

### المشكلة

تعدد مصادر القرار الفني قد يؤدي إلى تعارض القرارات
أو اختلاف منهج المراجعة.

### القرار

GPT هو قائد المشروع وصاحب القرار الفني والمراجع
المعماري النهائي.

تشمل مسؤوليته:

- تحليل المشروع.
- مراجعة المعمارية.
- مراجعة الوثائق.
- تحديد الخطوات.
- تقييم الاعتماديات.
- مراجعة التعديلات.
- اعتماد القرارات الفنية.
- الحفاظ على الاتساق المعماري.

مالك المشروع / المنفذ مسؤول عن:

- التطبيق المحلي.
- تشغيل الأوامر.
- الاختبارات المحلية.
- تنفيذ Git.
- تنفيذ المزامنة الفورية أول بأول.

### السبب

وجود جهة فنية واحدة مسؤولة عن الاتساق والقرار.

### التأثير

لا يتم اعتماد قرار معماري متعارض مع قرار GPT الفني
الموثق.

### الحالة

ACCEPTED

7. ADR-016 — توحيد ملكية وثائق المشروع وإزالة الوثائق التشغيلية المتداخلة
==================================================

التاريخ:

2026-08-11

الحالة:

ACCEPTED

المجال:

Project Governance / Documentation

### السياق

تراكمت وثائق متعددة تؤدي وظائف متقاربة، وبعضها أصبح يعكس Baseline تاريخية بدل الحالة الحالية.

### المشكلة

وجود أكثر من مصدر لنفس نوع المعلومة يزيد احتمال التكرار وتعارض المرحلة والمعمارية وتشتيت GPT والمطور.

### القرار

المصادر الرسمية الحالية هي:

GPT EXECUTION RULES
CONTROL INDEX
PROJECT CHARTER
WORK PROTOCOL
ARCHITECTURE
PROJECT STATE
ROADMAP
FUTURE ROADMAP
FUTURE PRODUCT VISION
ARCHITECTURE FINDINGS
DECISIONS
CHANGELOG
KNOWN PROBLEMS

وتم إلغاء الاعتماد التشغيلي على:

- ORION_EXECUTION_METHOD.md
- ORION_TARGET_ARCHITECTURE_IMPLEMENTATION_BASELINE.md

بعد دمج المبادئ المفيدة منهما في WORK PROTOCOL وARCHITECTURE وROADMAP.

### السبب

تقليل مصادر الحقيقة دون فقدان المعلومات المهمة أو تعطيل المطور.

### التأثير

كل وثيقة تملك نطاقًا واحدًا واضحًا، ولا تنشأ وثيقة جديدة لنفس الوظيفة دون قرار موثق.

### الحالة

ACCEPTED
